Program ini menggunakan algoritma rekursif, cara kerjanya adalah dengan mengakali aturan permainan. Untuk bisa memindahkan cakram paling bawah ke tiang tujuan, kita harus menyingkirkan semua cakram di atasnya. Program melakukan ini dengan menitipkan tumpukan cakram bagian atas ke tiang sementara. Setelah jalannya terbuka, cakram paling besar dipindah langsung ke tiang akhir. Terakhir, tumpukan cakram yang tadi dititipkan akan dipindah kembali untuk ditumpuk di atas cakram terbesar tersebut
